# 📂 Data

Ce dossier contient les données utilisées dans le projet **Automated Sales Reporting**.

## 📊 Données

Les fichiers présents dans `sample/` sont des données d'exemple utilisées uniquement à des fins de démonstration et d'apprentissage.

Les données peuvent contenir des informations telles que :

* identifiant de vente ;
* date de vente ;
* produit ;
* catégorie ;
* quantité ;
* prix unitaire ;
* montant ;
* informations commerciales.

## 🔐 Confidentialité

Aucune donnée client ou donnée commerciale confidentielle n'est utilisée dans ce dépôt.

Les données présentes sur GitHub sont des données d'exemple ou anonymisées.

## 🔄 Utilisation

Les données suivent le processus :

```text
Data
 ↓
Excel / VBA
 ↓
Python
 ↓
Power BI
```

Elles servent à démontrer le processus complet de contrôle, nettoyage, analyse et visualisation.
